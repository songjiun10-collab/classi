# LLM Wiki 📓

이 폴더는 **LLM(Claude)이 수정한 변경 이력**을 누적하는 Obsidian 호환 위키입니다.

- 이 디렉터리를 **Obsidian Vault로 열거나** 기존 Vault에 동기화해서 보세요.
- 규칙은 [`CLAUDE.md`](../CLAUDE.md)의 작업 원칙 **6. LLM Wiki 기록**을 따릅니다.

## 기록 규칙

파일을 수정할 때마다 변경 내용을 기록합니다. 항목:

- **날짜·시각**
- **수정한 파일** 경로
- **변경 요약** (왜·무엇을)
- **전체 diff** (`diff` 코드블록)

## 구조

- `README.md` — 이 안내(Vault 인덱스)
- `changes/` — 수정 1건당 노트 하나(`YYYY-MM-DD-<요약>.md`)

> 원격 환경에서는 사용자 PC의 로컬 Obsidian Vault에 직접 쓸 수 없어, 저장소 안 `llm-wiki/`에 남깁니다.
